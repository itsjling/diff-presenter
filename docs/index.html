How it works

From pull request to reason.

01

Point it at a PR.

Use a PR number, a GitHub URL, or an owner/repo name.

02

Read one file.

Move through the full change without losing the file in front of you.

03

Keep the reason close.

Codex writes a short note about what changed, why, and what to check.

Run locally

Start with the pull request.

Diff Presenter uses your current GitHub and Codex CLI logins. It opens a local review page and leaves your checkout alone.

npx diff-presenter --pr 198

Outside a checkout: npx diff-presenter --repo owner/repo --pr 198
