## Findings considered and rejected

- Probe every coding-agent login in `doctor`: rejected because the five CLIs
  have no shared stable, side-effect-free auth check. Running a real prompt can
  send data, cost money, or create a session.
- Fall back to another provider after an installed agent fails: rejected
  because it could send a diff to a provider the user did not expect. The docs
  will tell users how to select another agent.
- Put the full target and option reference in the root README: rejected because
  `AGENTS.md` keeps that file to command use and local development, and a copy
  would drift.
- Generate the whole CLI guide from code: rejected because examples, warnings,
  and task flow need human editing. Plan 007 generates and checks only factual
  tables.
- Keep default worktree notes in the target repo and only document the write:
  rejected because the product promises to preserve the target repo and an
  unignored `.diffsplain/` path can dirty it.
- Claim that an installed agent is ready: rejected because `--version` proves
  only that the executable runs.
